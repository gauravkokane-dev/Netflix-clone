# Netflix Clone

A responsive Netflix Clone built using HTML and CSS.

## Features

- Responsive Navbar
- Hero Section
- Movie Cards
- Hover Effects
- Modern Netflix UI Design
- Responsive Layout

## Technologies Used

- HTML5
- CSS3

## Project Purpose

This project was created to practice frontend web development skills and improve HTML/CSS design concepts.
